# فهرس — القانون المتعلق بالعقوبات البديلة

- الباب الأول المكرر: في العقوبات البديلة
  - الفرع 1: أحكام عامة
    - الفصل 35-1. - العقوبات البديلة هي العقوبات التي يحكم بها بديلا للعقوبات السالبة (المادة )
    - الفصل 35-2. - تحدد العقوبات البديلة في: (المادة )
    - الفصل 35-3. - لا يحكم بالعقوبات البديلة في الجنح المتعلقة بالجرائم التالية: (المادة )
    - الفصل 35-4. - إذا قررت المحكمة الحكم بالعقوبة الحبسية المشار إليها في الفقرة (المادة )
  - الفرع 2: العمل لأجل المنفعة العامة
    - الفصل 35-5. - يمكن للمحكمة أن تحكم بعقوبة العمل لأجل المنفعة العامة بديلا للعقوبة (المادة )
    - الفصل 35-6. - يكون العمل لأجل المنفعة العامة غير مؤدى عنه، وينجز لمدة تتراوح (المادة )
    - الفصل 35-7. - يلتزم المحكوم عليه بتنفيذ عقوبة العمل لأجل المنفعة العامة داخل أجل (المادة )
    - الفصل 35-8. - إذا قررت المحكمة الحكم على الحدث بعقوبة حبسية وفقا للمادة 482 (المادة )
    - الفصل 35-9. - تطبق على أنشطة العمل لأجل المنفعة العامة المقتضيات التشريعية (المادة )
  - الفرع 3: المراقبة الإلكترونية
    - الفصل 35-10. - يمكن للمحكمة أن تحكم بالمراقبة الإلكترونية بديلا للعقوبة السالبة (المادة )
  - الفرع 4: تقييد بعض الحقوق أو فرض تدابير رقابية أو علاجية أو تأهيلية
    - الفصل 35-11. - يمكن للمحكمة أن تحكم بالعقوبة المقيدة لبعض الحقوق أو فرض تدابير (المادة )
    - الفصل 35-12. - العقوبات المقيدة لبعض الحقوق أو فرض تدابير رقابية أو علاجية أو (المادة )
    - الفصل 35-13. - يلتزم المحكوم عليه بتنفيذ العقوبات المقيدة لبعض الحقوق أو فرض (المادة )
  - الفرع 5: الغرامة اليومية
    - الفصل 35-14. - يمكن للمحكمة أن تحكم بعقوبة الغرامة اليومية بديلا للعقوبة الحبسية (المادة )
    - الفصل 35-15. - يحدد مبلغ الغرامة اليومية بين 100 و 2.000 درهم عن كل يوم من (المادة 3)
- الباب الخامس المكرر: تنفيذ العقوبات البديلة (المادة )
  - الفرع الأول: تدابير تنفيذ عقوبة العمل لأجل المنفعة العامة (المادة )
  - الفرع الثاني: تدابير تنفيذ المراقبة الإلكترونية (المادة )
  - الفرع الثالث: تدابير تنفيذ عقوبة تقييد بعض الحقوق أو فرض تدابير رقابية أو علاجية أو تأهيلية (المادة )
  - الفرع الرابع: تدابير تنفيذ الغرامة اليومية (المادة 4)
