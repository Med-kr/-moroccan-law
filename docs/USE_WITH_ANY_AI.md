# Use it with any AI / استعمله مع أي ذكاء اصطناعي / Avec n'importe quelle IA

The texts and tools are not tied to Claude. Four ways in, from the most capable to the simplest:

| Way | For | What the AI gets |
|---|---|---|
| **MCP server, local** (`mcp/server.py`) | Any app that speaks MCP: Claude Desktop, Cursor, VS Code (Copilot), Windsurf, Gemini CLI, Codex CLI, LM Studio, Claude Code… | 8 tools: list / find texts, read articles, ranked search, table of contents, provenance, catalog of 7,150 official documents |
| **MCP server over HTTP** (`--http`) | Apps that take a URL: ChatGPT connectors, hosted agents | the same tools (without the PDF download) |
| **Claude skills** (`skills/`) | Claude Code, Claude apps | the tools plus the rules of use (never cite from memory, date the version, application in time) |
| **Dataset** (`exports/moroccan-law-articles.jsonl.gz`) | Anything: your own RAG, a search index, a notebook, a file upload | 41,410 articles, one JSON line each, with source and version |

Everything needs **Python 3.10+** and nothing else (standard library only).

```bash
git clone https://github.com/Med-kr/moroccan-law.git
cd moroccan-law
python3 mcp/server.py --self-test        # every tool answers: ok
```

Below, replace `/ABS/PATH` with the absolute path of the cloned folder (`pwd` prints it).
Menus and file locations change between versions of these apps: if one has moved, look for
"MCP servers" in the app's settings or documentation; the server part (`command` + `args`) stays the same.

## 1. Local MCP server

The common block, used by most apps:

```json
{
  "mcpServers": {
    "moroccan-law": {
      "command": "python3",
      "args": ["/ABS/PATH/mcp/server.py"]
    }
  }
}
```

| App | Where it goes |
|---|---|
| **Claude Desktop** | Settings → Developer → Edit Config (`claude_desktop_config.json`), block above; restart the app |
| **Cursor** | `~/.cursor/mcp.json` (all projects) or `.cursor/mcp.json` (one project), block above |
| **Windsurf** | `~/.codeium/windsurf/mcp_config.json`, block above |
| **Gemini CLI** | `~/.gemini/settings.json`, block above (key `mcpServers`) |
| **LM Studio** | Program tab → Install → Edit `mcp.json`, block above; use a model that supports tool calls |
| **Claude Code** | `claude mcp add moroccan-law -- python3 /ABS/PATH/mcp/server.py` (or the plugin, see README) |
| **VS Code (GitHub Copilot, agent mode)** | `.vscode/mcp.json`, with `servers` instead of `mcpServers`: |

```json
{ "servers": { "moroccan-law": { "type": "stdio", "command": "python3", "args": ["/ABS/PATH/mcp/server.py"] } } }
```

**Codex CLI** (`~/.codex/config.toml`):

```toml
[mcp_servers.moroccan-law]
command = "python3"
args = ["/ABS/PATH/mcp/server.py"]
```

On Windows, use `python` (or the full path of `python.exe`) and a path such as
`C:\\Users\\you\\moroccan-law\\mcp\\server.py`.

Then ask, in Arabic, French or darija: « ch7al mn youm 3ndi bach nsta2nef 7okm ? ». The AI
should call `search_articles`, then `get_article`, and quote article 204 of law 58.25 with its source.

## 2. MCP over HTTP (apps that take a URL)

```bash
python3 mcp/server.py --http --port 8765 --token "$(openssl rand -hex 16)"
# -> http://127.0.0.1:8765/mcp      (health check: GET /health)
```

- It listens on **localhost only** by default and refuses requests from web pages of other origins.
- An app on the internet (ChatGPT connectors, hosted agents) needs an **HTTPS** URL: put the
  server behind a reverse proxy or a tunnel you control, and keep `--token` (sent as
  `Authorization: Bearer <token>`). If an app cannot send a token, expose the server only for
  the time of the session.
- The tool that downloads PDFs is switched off in this mode; `catalog_show` still gives the
  official PDF link.
- The texts are public law; the server reads only the files of this repository.

## 4. Dataset

`exports/moroccan-law-articles.jsonl.gz`, regenerated by `python3 scripts/export_dataset.py`.

```json
{"id": "msm-58-25:204", "text": "msm-58-25", "law": "القانون رقم 58.25 المتعلق بالمسطرة المدنية",
 "article": "204", "path": "القسم الثالث … › الباب السابع: الاستئناف", "body": "…",
 "footnotes": {}, "language": "ar", "version_date": null,
 "source_url": "https://adala.justice.gov.ma/api/uploads/…pdf", "reviewed": true}
```

Load it into a vector store or a search engine, or upload it to an AI that accepts files. Keep
`source_url` and `version_date` with every chunk, so that answers can cite them.

## Rules to give any AI that uses these texts

Paste this into the system prompt or the instructions of your assistant:

> You answer questions on Moroccan law only from the texts returned by the moroccan-law tools.
> Never quote an article from memory: look it up (`search_articles`, then `get_article`). Cite the
> law, the article number and the exact Arabic wording of the decisive passage; a translation is
> unofficial and only the Arabic text is authentic. Give the version date and the official link
> returned by the tool. If the facts may predate the law or its last amendment, read the
> transitional provisions. If an article is not found, say so; never reconstruct it. There is no
> case law in these tools: never invent a court decision. Texts marked `reviewed: false` come from
> automatic extraction: say so and advise checking the official PDF. This is legal information,
> not legal advice.
